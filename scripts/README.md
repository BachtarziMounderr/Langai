# Futurs scripts

Ce dossier accueillera les utilitaires de base de données, la préparation locale, les données initiales (seed data) et la maintenance. Les langues seront des données configurables, jamais des branches de code. Ajouter les scripts avec leurs besoins réels, documenter les prérequis et signaler les opérations destructives. Aucun script métier ou opérationnel créé à cette étape.
